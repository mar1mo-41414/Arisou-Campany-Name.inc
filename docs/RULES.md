# ルールの意味と、「ありそう」に見える理由

画面で選べるルールを上から順に説明します。実装の詳細は [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 文字種

**漢字 / カタカナ / ひらがな / 英字**から、使ってよいものを選びます（複数選択）。

| 選び方 | 出てくる名前の傾向 | 例 |
| --- | --- | --- |
| 漢字だけ | 老舗・地方企業っぽい。いちばん「会社名」らしい | 株式会社秀英運輸、株式会社瑞光興産 |
| カタカナだけ | 平成以降の会社、外資系、IT・サービス | 株式会社コスモス電子、グランツケア株式会社 |
| 英字だけ | スタートアップ、IT、グローバル | 株式会社ZENITH、SKYLINE株式会社 |
| ひらがなだけ | 小規模、個人商店、デザイン系 | 有限会社こもれび |
| 漢字＋カタカナ | 現実の社名にいちばん多い組み合わせ | 株式会社金光システム、シリウス衛生株式会社 |
| カタカナ＋英字 | グローバル系 | プログレスワークス株式会社、株式会社AXIOM |

複数選ぶと、主語と接尾辞で**違う文字種**を使えます。「漢字の主語＋カタカナの接尾辞」が
いちばん社名らしく、「ひらがな＋英字」「英字＋漢字」は不自然なので避けています。

## 2. 文字数

「法人種別を除いた本体」の長さです。日本の社名は **3〜6文字**に集中するので、
既定値は 3〜6 にしてあります。

| 範囲 | 印象 |
| --- | --- |
| 2〜3 | 短い。屋号・小店舗・IT系 |
| 4〜6 | いちばん普通。迷ったらここ |
| 7〜10 | 長い。カタカナ・英字・業種接尾辞つきで届く |
| 11以上 | かなり長い。ほぼカタカナ/英字＋長い接尾辞 |

条件が厳しすぎて作れないとき（例: 英字だけ・1〜2文字）は、条件に一番近い名前を出して
「文字数に収まらなかった」と警告します。0件にはなりません。

## 3. 法人種別

| 種類 | 形 | 使われ方 |
| --- | --- | --- |
| 株式会社 | 株式会社◯◯ / ◯◯株式会社 | いちばん多い。「(株)」と略される |
| 有限会社 | 有限会社◯◯ | 小規模。2006年以降は新設できないが、既存の社名は残っている |
| 合同会社 | 合同会社◯◯ | 2006年以降。ベンチャー・小規模に多い |
| 合名会社 / 合資会社 | ◯◯ | 数は少ないが、いまも存在する |
| 付けない（屋号のみ） | ◯◯ | 商店・ブランド名・個人事業 |

**株式会社の位置（前株 / 後株）**

- 前株「株式会社◯◯」が多数派。自動モードでも約 7 割を前株にしています。
- 後株「◯◯株式会社」は少数派ですが実在します。漢字の社名だと古い会社に多い印象があります。
- ただし本体が「製作所」「工務店」「不動産」などで終わるときに後株にすると
  「千歳製作所株式会社」のような二重接尾辞に見えるので、自動モードではほぼ前株にします。

**有限会社などは必ず前**です（「◯◯有限会社」という登記はできません）。

## 4. 業種

業種を選ぶと、**接尾辞の傾向**が変わります。業種そのものを決めるわけではありません。

| 業種 | 漢字 | カタカナ | 英字 |
| --- | --- | --- | --- |
| 商社・貿易 | 商事, 物産, 交易, 興産, 通商, 産業, 商会 | トレーディング, コマース, ジャパン | TRADING, COMMERCE, JAPAN |
| 製造・ものづくり | 製作所, 工業, 電機, 精機, 鉄工, 化成, 食品 | テクノス, インダストリー, マシナリー | INDUSTRIES, PRECISION |
| 建設・不動産 | 建設, 工務店, 地所, 不動産, 住建, 開発 | コンストラクション, ハウジング | CONSTRUCTION, HOMES |
| IT・通信 | 情報, 電算, 通信, 電子 | システムズ, ソリューションズ, ネットワークス, デジタル | SYSTEMS, SOLUTIONS, NETWORKS |
| サービス・小売 | 興業, 企画, 事務所, 商店 | サービス, マート, クリエイト | SERVICE, MART, CREATE |
| 運輸・物流 | 運輸, 運送, 物流, 倉庫, 海運 | ロジスティクス, エクスプレス | LOGISTICS, EXPRESS |
| 金融・保険 | 証券, 保険, 信託, 金融 | ファイナンス, キャピタル, パートナーズ | FINANCE, CAPITAL, PARTNERS |
| 医療・福祉 | 薬局, 福祉, 衛生 | メディカル, ケア, クリニック | MEDICAL, CARE, CLINIC |
| エンタメ・メディア | 出版, 映像, 音楽, 印刷, 広告 | プロダクション, スタジオ, メディア | PRODUCTION, STUDIO, MEDIA |
| 持株・グループ | 本社, 総業 | ホールディングス, グループ, ワークス | HOLDINGS, GROUP, WORKS |

- **未選択** = すべての業種から選ぶ（接尾辞が付くかどうかも確率次第）
- **接尾辞なし** = 「四国宏和」「阿蘇明和」のような、接尾辞を付けない名前だけになる

## 5. 数字

「青葉88建設」「ATLAS21」のように、本体と接尾辞のあいだに数字を挟みます。

- 数字は**接尾辞のまえ**に入れます。末尾に置くと「三和5株式会社」のように浮きます。
- 2桁以上を多めにしています（1桁は「三和5」のように不自然に見えるため）。

## 6. シード

同じシード＋同じルールなら、同じ名前が同じ順番で出ます。

- シード欄が**空**のときは、押すたびに新しいシードが振られ、毎回違う名前が出ます。
- シード欄に**値がある**ときは、そのシードに固定されます。何度押しても同じ結果です。
- 結果の下の「固定する」を押すと、いま出ている結果のシードが欄に入ります。
- 「ランダムに固定」はシードを振って固定します。「別のシードで」は欄を空にして引き直します。
- URL の `?seed=xxxx` でも指定できます。結果を人に渡すときに使えます。
- 語彙や確率を変えると、同じシードでも結果は変わります（バージョンが変われば別物）。

## 7. 生成数

1〜20件。1件だけ出して決める使い方も、20件見て選ぶ使い方もできます。
上限は `generator.js` の `MAX_COUNT`、`app.js` の `MAX_COUNT`、`index.html` の `input max` で管理しています。

## 8. 「ありそう」の正体

派手な仕掛けはありません。効いているのは次の4つです。

1. **語彙が実在の社名に寄っている**（大成・明和・金光・千歳のような、実際によくある漢語）
2. **地名を頭に付ける**（博多・霧島・姪浜のような地域名は社名の定番）
3. **文字種の混在を許す**（漢字＋カタカナが現実の多数派）
4. **不自然な組み合わせを確率で避ける**（二重接尾辞、ひらがな＋英字など）

つまり「生成AI的な意外さ」ではなく、**日本の社名の統計的な癖をなぞっている**だけです。
だから実在の会社と一致することがあります。
