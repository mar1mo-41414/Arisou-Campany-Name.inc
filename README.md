# Arisou-Campany-Name.inc

[English README →](README-EN.md)

**ありそうな会社名**を生成する Web ツールです。ルール（文字種・文字数・法人種別・業種など）を選んで
「生成する」を押すと、いかにも日本のどこかに存在していそうな社名が並びます。

> [!NOTE]
> 生成結果はすべてブラウザ内で作られます。サーバーも通信も使いません。
> **実在の会社名と偶然一致することがあります**（それは「ありそう」の証拠です）。
> 実在しない会社名を、実在する会社の名前として使わないでください。

## 使い方

1. `web/index.html` をブラウザで開く（ダブルクリックで動きます）
2. ルールを選ぶ
3. 「生成する」を押す

`http://` で見たいときは、リポジトリ直下で確認用の静的サーバーを起動します。

```bash
python3 tools/serve.py          # http://localhost:8000/
python3 tools/serve.py --port 9000 --host 0.0.0.0
```

## 選べるルール

| ルール | 内容 |
| --- | --- |
| 文字種 | 漢字 / カタカナ / ひらがな / 英字（複数選択可）。混在も作れる |
| 文字数 | 本体（法人種別を除く）の最小・最大。例: 3〜6 文字 |
| 法人種別 | 株式会社 / 有限会社 / 合同会社 / 合名会社 / 合資会社 / 付けない（屋号のみ） |
| 位置 | 株式会社のみ前株（株式会社◯◯）・後株（◯◯株式会社）・自動 |
| 業種 | 接尾辞の傾向（商事・製作所・システムズ・ホールディングスなど）。未選択なら全部、「接尾辞なし」も選べる |
| 数字 | 「青葉88建設」のように名前に数字を入れる |
| シード | 空なら押すたびに別の結果。入力して固定すると、同じシード＋同じルールで同じ結果（再現・共有できる） |
| 生成数 | 1 回に 1〜50 件 |

プリセット（和風商事 / IT・システム / グローバル / ひらがな系）で、よくある組み合わせを一発で選べます。

## 出力例

```
株式会社対馬明星   (つしまみょうじょう)
姪浜東栄株式会社   (めいのはまとうえい)
株式会社コスモス電子 (こすもすでんし)
グランツケア株式会社 (ぐらんつけあ)
株式会社千歳製作所  (ちとせせいさくしょ)
株式会社金光システム (きんこうしすてむ)
```

各カードには **よみがな・文字数・タグ**（業種、地名、混在など）が付きます。
「コピー」で1件ずつ、「全部コピー」でまとめてコピーできます。

結果の下に「使ったシード」が出ます。「固定する」を押すとシード欄に入り、何度生成しても同じ名前になります。
`?seed=xxxx` を URL に付けても同じことができます。

## 構成

```
web/index.html      画面
web/app.js          ルールの読み取り・表示・コピー（UI のみ）
web/generator.js    名前の生成ロジック（依存なし・ブラウザ/Node 両対応）
tests/              generator.js の単体テスト（Node のみ、依存パッケージ不要）
tools/serve.py      確認用の静的サーバー（Python 標準ライブラリのみ）
docs/               仕組みと考え方
AGENTS.md           作業する人・エージェント向けの指針
```

## テスト

```bash
node tests/generator.test.js
```

Node 18 以降。npm install は不要です。シード固定で決定論的に動くので、乱数のぶれはありません。
