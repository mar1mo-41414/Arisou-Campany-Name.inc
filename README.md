# Arisou-Campany-Name.inc

**ありそうな会社名**を、気の向くままに作る Web ツールです。

> [!NOTE]
> これはおもちゃです。実在する会社かどうかを調べたり、会社を作ったりするものではありません。
> 実務や法務・商標の確認を想定していません。実在の会社名と偶然一致することがあります。

## できること

- ルールを選んで「生成する」を押すと、会社名を一度に最大20件生成
- 文字種（漢字 / カタカナ / ひらがな / 英字）を複数選べる。混在した社名も作れる
- 本体の文字数（法人種別を除く）を最小・最大で指定
- 法人種別（株式会社 / 有限会社 / 合同会社 / 合名会社 / 合資会社 / 屋号のみ）と、株式会社の前株・後株
- 業種（10種）で接尾辞の傾向を変える。接尾辞なしも選べる
- 名前に数字を入れる（`株式会社青葉88建設` のような形）
- シードを固定すると、同じ会社名を何度でも再現できる
- 結果をクリックで1件コピー、「すべてコピー」で改行区切りでコピー

生成はブラウザ内で完結します。サーバーへの送信や、ファイルの作成は行いません。

## 使い方

`index.html` をブラウザで開くだけです。インストールやビルドは不要です。

```bash
git clone https://github.com/mar1mo-41414/Arisou-Campany-Name.inc.git
cd Arisou-Campany-Name.inc
# index.html をブラウザで開く
```

1. 文字種・文字数・法人種別・業種を設定します（「プリセット」でよくある組み合わせを一発で選べます）。
2. 必要なら「名前に数字を入れる」とシードを設定し、「生成する」を押します。
3. 結果のカードをクリックすると1件、「すべてコピー」でまとめてコピーできます。

コピー機能はブラウザのクリップボード機能を使います。利用できない環境ではブラウザの従来のコピー機能を試します。

### ルールについて

- **文字数**は法人種別を含まない本体の長さです（1〜20文字）。`株式会社` を付けてもの字数は変わりません。
- **文字種**は複数選べます。主語と業種接尾辞で違う文字種を使うことがあり、それが「ありそう」に見える理由のひとつです。
  漢字＋カタカナがいちばん現実に近く、ひらがな＋英字、英字＋漢字は不自然なので避けています。
- **株式会社の位置**は「自動」だと前株が多めです。本体が `製作所` `工務店` `不動産` などで終わるときは、
  `千歳製作所株式会社` のような二重接尾辞を避けるためほぼ前株になります。
- **有限会社・合同会社・合名会社・合資会社**は必ず前株です（`◯◯有限会社` という形は作りません）。
- **業種**は接尾辞の傾向だけを変えます。「接尾辞なし」を選ぶと `四国宏和` のような屋号だけの名前になります。
- **数字**は本体のあと・業種接尾辞のまえに入ります（`三和5株式会社` のような末尾の数字は作りません）。
- **シード**が空のときは押すたびに別の結果になります。値があるときは固定され、何度押しても同じ結果です。
  結果の下の「固定する」で、いま出ている結果のシードを欄に入れられます。`?seed=xxxx` を URL に付けても同じです。
- 条件が厳しすぎて文字数に収まる名前が作れないときは、条件に一番近い名前を出して警告します。
  黙って0件にはなりません。
- 使える文字種を1つも選んでいないときは生成しません（警告を出します）。
- 語彙の組み合わせの都合で、同じ名前が2回出ることはありません。ただし条件が厳しいと、生成数に満たないことがあります。

## 構成

```
index.html      画面
style.css       スタイル
generator.js    生成ロジック（UI に依存しない。Node からも実行できる）
app.js          画面操作（ルールの読み取り、表示、コピー）
test/           テスト
docs/           仕組みと考え方
```

## テスト

Node.js があれば、依存パッケージなしで実行できます。

```bash
node --test
```
